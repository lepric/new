# Деплой и регистрация VK Mini App

## 📋 Быстрая инструкция по деплою

### 1. Включить GitHub Pages
- Перейдите на https://github.com/lepric/new
- Settings → Pages
- Source: Main branch, /root folder
- GitHub Pages будет доступен на: **https://lepric.github.io/new/**

### 2. Зарегистрировать приложение в VK
1. Перейдите на https://vk.com/apps
2. Создайте новое приложение типа **VK Mini App**
3. Установите основные данные:
   - Название: "Напоминания об оплате"
   - Platform: Web
   - Main page URL: `https://lepric.github.io/new/`

### 3. Настроить разрешения приложения
В настройках приложения в VK добавьте разрешения:
```
- photos: Доступ к фотографиям
- stories: Для отправки уведомлений
```

### 4. Получить App ID
После создания приложения вы получите App ID. Замените `51670957` на ваш ID в файле `vk-config.js`.

## 🔧 Конфигурация

### vk-config.js
Содержит инициализацию VK Bridge и настройку для VK SDK.
**Важно:** Обновите `apiId` на ID вашего приложения

```javascript
VK.init({
    apiId: 51670957, // ← Замените на ваш App ID
});
```

### app.js
Приложение автоматически:
- Получает информацию о пользователе VK через VK Bridge
- Сохраняет напоминания в localStorage
- Отправляет уведомления через VK Bridge API

## 📱 Тестирование

### Локальное тестирование
```bash
python3 -m http.server 8000
# Откройте http://localhost:8000
```

### Тестирование в VK
После регистрации приложение будет доступно по ссылке вида:
```
https://vk.com/app{APP_ID}
```

## 🚀 Использование

1. **Создать напоминание** - Укажите название, текст, дату/время и периодичность
2. **Просмотреть напоминания** - Отобразит все ваши напоминания
3. **Удалить напоминание** - Удалит выбранное напоминание

## 📊 Данные

- Все напоминания хранятся в `localStorage` браузера
- Данные привязаны к пользователю VK (через `userId`)
- При очистке кэша браузера напоминания будут удалены

## 🔐 Безопасность

- Приложение не требует серверной части для работы
- Все данные хранятся локально у пользователя
- Не собираются и не передаются персональные данные
